# Khosra plugin

This is a portable Agent Plugins package for the existing Khosra MCP server. It includes Khosra's square logomark for the listing and composer, with light and dark variants. The server supplies OAuth discovery and dynamic client registration for manuscript read/propose access; select OAuth in the connection setup. There are no passwords, tokens, manuscript records, hooks or executable code in the package. Khosra's live guide provides the current tool inventory and workflows.

## Build

From the repository root:

```sh
python3 scripts/package-plugin.py
```

This writes `releases/khosra-0.2.0-chatgpt-plugin.zip` and a SHA-256 sidecar. The manifest, MCP configuration and assets sit at the ZIP root. The ordinary website packaging command also builds this separate plugin archive.

For another deployment, use `python3 scripts/package-plugin.py --origin https://writer.example.org`. This changes only public deployment URLs in the generated archive, leaving the source manifests untouched. Do not include a path, query, fragment or credentials in the origin.

## Apply branding in ChatGPT

Website/SFTP uploads do not install this package or change an existing ChatGPT connection's icon.

For a plugin managed in the OpenAI developer dashboard, use its **Upload plugin** flow to import this ZIP, verify the imported name/icons and connect the remote MCP endpoint using OAuth. Follow the dashboard's available draft/testing workflow before publishing anything. Do not upload this ZIP to the website document root. Local/repository marketplace installation is another testing option on clients that support it; availability varies by surface and account.

For an existing custom MCP connection, check its management screen for a name/icon upload control. If that control is available, use the included light/dark SVGs (or the PNG copies generated by `node scripts/render-plugin-icons.mjs`) without replacing the working connection. If it only permits endpoint/tool refresh, refreshing cannot be relied on to import these package branding fields; use a supported packaged-plugin workflow instead. This package references the same server URL but does not contain an account-specific registered plugin ID or automatically modify your current connection.

After installation, sign in through Khosra's consent page if prompted, start a new conversation and verify the icon, `get_khosra_guide`, a chapter read and a saved proposal. Never include your owner password or OAuth credentials in a ZIP. Existing author approval gates remain in Khosra.

## Publication status

This is a branding/connection package for private testing, not a published or approved directory listing. Public submission additionally requires real support, privacy-policy and terms URLs, review fixtures/credentials supplied privately, demonstrated test cases and a walkthrough. Those materials have not been fabricated or bundled. Local checks cannot confirm how a particular ChatGPT account renders the icon.

The icons are generated from `public/favicon.svg`: its path geometry and two brand colors are preserved; square dimensions and a paper-colored background keep the cutout outline visible on either theme. Edit the source mark and rebuild rather than editing generated icons.

Official references: [Package your plugin](https://developers.openai.com/plugins/build/plugins), [brand assets and submission](https://developers.openai.com/plugins/deploy/submission), [connect and test](https://developers.openai.com/plugins/deploy/connect-chatgpt).
